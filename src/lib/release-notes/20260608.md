sveltekit의 resolve를 사용할때 발생했던 에러는 routing 네이밍을 통일시키지 않아서 발생했다.  
routing 폴더는 `/blog/[slug]` 였지만 `resolve('/blog/[id], { id: key })` 로 사용한 것이 실수였다. 이름을 일치시켜주니 해결되었다.  
dev running 상태에서 동적으로 계속 routing list 를 갱신하고 해당 routing list 로 ts 엔진이 오류를 감지했다.

- 이제 글을 써야한다.
- 다음 기능을 개발하기 전에 리팩토링을 계획하고 진행할 것이다.
