3일간 작업을 미루다가 다시 잡았다.  
작은 체크리스트를 만들어서 벽에 붙였다. 조금 우스꽝스러운 모습이지만 효과는 지금까지 시도한 것 중 가장 뛰어나다. 나를 다시 작업으로 돌아오게 만들었으니까.
오늘은 목록 화면을 작업했고 이제 보여지는 부분은 거의 작업이 완료되었다.
레이아웃 잡는 것에 익숙해졌다. flexbox로 해결할 수 있는 문제는 최대한 flex를 활용하는 것을 의식하게 되었다.
width 100% 대신 grow를 쓴다던가 margin/padding 대신 gap으로 해결하는 방법을 찾았다.
tailwindcss 의 공식문서가 필요한걸 잘 찾아갈 수 있도록 구성되어 있어서 훨씬 쉽게 익숙해졌다.
많은 요소를 다루면서도 최소한의 깊이를 유지한 점에서 배울점이 있었다.

- 조금 더 복잡하고 더 재미있는 일이 남았다. 스크립트를 작성할 시간이다.
- 글이 적절한 경로로 연결되야 하고 추가에도 문제없이 대응되야 한다.
